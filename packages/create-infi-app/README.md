# create-infi-app

```bash
npm create infi-app@latest minha-loja -- --template ecommerce
```

Scaffolds an Infi template, logs you in in the browser (or with a code, for an
AI agent: `--device`), gives the project its own `sk_test_` and seeds the
catalog on your sandbox with `infi sync`. The same thing as `infi init`.
